# Проверки AMAI UI 1.0.0

Проверено 2 ноября 2026 года. Проверки в браузере на локальном HTTP-сервере; ширина viewport задавалась явно.

- 1440×1000: десктоп, четыре KPI, боковая навигация; ширина страницы соответствует viewport.
- 768×1024: планшетная раскладка, крупные действия 52 px.
- 390×844: мобильные карточки, диалог, ошибка формы; ширина страницы 390 px.
- 320×740: ширина страницы 320 px, включая длинное описание и длинное слово в списке.
- Исправлено растягивание grid из-за минимальной ширины таблицы; таблица прокручивается только внутри своего контейнера.
- Пустая форма показывает ошибку и получает фокус; заполненная добавляет запись в таблицу и список, обновляет число записей.
- Вкладки переключаются кликом и стрелкой влево; активная панель и aria-selected обновляются.
- Диалог открывается с фокусом в поле, проверяет пустое значение, добавляет запись и закрывается. Escape возвращает фокус на кнопку открытия.
- Повтор загрузки показывает ожидаемое состояние и затем сообщение восстановления.
- Ошибок JavaScript в журнале браузера во время проверки не обнаружено.
- Синтаксис demo.js проверен node --check.
- SKILL.md прошёл штатный quick_validate.py; PyYAML установлен только во временную папку для проверки.

## Контраст

Численно рассчитан по относительной яркости sRGB. Полные значения в contrast.json.

- Основной текст / белый: 15,58:1.
- Вторичный текст / фон: 4,80:1.
- Белый текст / основная кнопка: 5,47:1.
- Тексты статусов / соответствующий фон: от 5,16:1.
- Граница поля / белый: 3,21:1.

## Ограничения

Это не полный аудит WCAG. Физические планшеты, экранные дикторы и все браузеры не проверялись. Реальный Inter и официальный графический логотип не вложены. Предпочтение уменьшенной анимации поддерживается CSS, системный режим отдельно не переключался. Взаимодействия примеров используют память страницы, а не сервер. Производственные системы не менялись.
