# AMAI UI · 1.0.0

Переносимый UI-пакет для новых продуктов AMAI Tech. Собран по локальным стилям мониторинга эффективности и планшетов Троль Авто. Это самостоятельная библиотека оформления; действующие системы не изменены.

## Быстрый просмотр

Открой `index.html` двойным щелчком в браузере. Все ресурсы локальные, сборка и интернет не нужны. Формы, вкладки, диалог, уведомления и повтор загрузки работают как примеры. Записи существуют только в памяти страницы и исчезают при перезагрузке.

Альтернативный запуск из директории пакета:

```sh
python3 -m http.server 8894 --bind 127.0.0.1
```

Открой http://127.0.0.1:8894. Остановка — Ctrl+C.

## Использование в другом чате

Приложи ZIP и напиши:

> Изучи SKILL.md из amai-ui и используй его CSS и правила при создании интерфейса. Нужен экран [описание]. Сохрани существующую бизнес-логику проекта.

Для установки в качестве локального скилла скопируй **всю папку `amai-ui`** в каталог навыков своего агента, например `~/.codex/skills/amai-ui`. Затем открой новый чат и используй `$amai-ui`. Пакет в этой поставке подготовлен для переноса; глобальные настройки агента автоматически не изменялись.

## Подключение в приложение

```html
<link rel="stylesheet" href="amai-theme.css">
<link rel="stylesheet" href="amai-components.css">
<div class="amai-ui">
  <section class="amai-card amai-stack">
    <h2>Новая запись</h2>
    <div class="amai-field">
      <label for="note">Описание</label>
      <textarea class="amai-input" id="note"></textarea>
    </div>
    <div><button class="amai-btn amai-btn--primary" type="button">Сохранить</button></div>
  </section>
</div>
```

В React используй `className`, в Vue обычный `class`. Подключай CSS глобально один раз, а поведение реализуй средствами приложения. Порталы диалогов должны наследовать `.amai-ui`. Сам `dialog` открывается через `showModal()`; CSS не открывает окно и не реализует обработчики.

`demo.css` и `demo.js` в рабочее приложение обычно не нужны: это оформление библиотеки и учебные обработчики. В примере кнопки «Сохранить» и «Отменить действие» только показывают уведомление; «Добавить запись» меняет локальный журнал. Ни одна кнопка не пишет на сервер.

## Настройка

Тема задаётся CSS-переменными `--amai-*`. Переопределения добавляй после темы на своём `.amai-ui`. Рекомендуется менять весь смысловой набор, например основной цвет вместе с hover и focus, а не случайные отдельные hex.

- `--amai-bg`, `--amai-surface`, `--amai-ink`, `--amai-muted`, `--amai-line`: поверхности, текст, разделители.
- `--amai-brand`: яркий синий для графики; `--amai-primary` и `--amai-primary-hover`: доступные действия.
- `--amai-space-*`, `--amai-radius-*`, `--amai-control`: плотность и геометрия.
- `data-density="touch"` на `.amai-ui`: крупные элементы. На устройствах с coarse pointer включаются автоматически.
- `.amai-shell` + `.amai-sidebar` + `.amai-main`: каркас с навигацией, необязательный для планшетного сценария.
- `.amai-grid`, `.amai-kpis`, `.amai-row`, `.amai-stack`: сетки и отступы.
- `.amai-btn` с модификаторами `--primary`, `--ghost`, `--danger`; нативный disabled для недоступных действий.
- `.amai-input` внутри `.amai-field`: input, select, textarea; aria-invalid, readonly, disabled показывают состояния.
- `.amai-tabs` + `.amai-tab`: внешний вид вкладок. Клавиатурный пример — в demo.js.
- `.amai-badge--success/--warning/--danger`, `.amai-alert--warning/--error`: статусы.
- `.amai-table-wrap` + `.amai-table`, `.amai-list`: таблицы и списки.
- `.amai-dialog`, `.amai-toast`, `.amai-skeleton`, `.amai-spinner`: обратная связь.

Точки перестройки: 1100 px — KPI в две колонки, 800 px — навигация сверху и формы в одну колонку, 480 px — KPI в одну колонку. Точки являются CSS-константами, а не переменными. Длинную таблицу прокручивай внутри региона; пример списка даёт альтернативное представление.

## Шрифт и логотип

Inter указан первым в стеке, но файл шрифта не вложен и не скачивается. Если Inter отсутствует, используется системный шрифт. Для одинаковой типографики на всех устройствах добавь локальные лицензированные файлы Inter и @font-face. Демо использует текстовую надпись «АМАИтех», не официальный графический логотип.

## Источники и принятые решения

Локальные исходные файлы AMAI-brain:

- `02_Companies/КУДО/Подразделения/Троль Авто/Projects/Улучшение системы эффективности/Interface/dist/styles.css` — палитра, карточки, боковая навигация, компактные данные.
- `02_Companies/КУДО/Подразделения/Троль Авто/Projects/Планшеты/Interface/dist/style.css` — сенсорные формы, крупные действия, диалоги.

Унифицированы Inter/системный стек вместо двух разных стеков, шкала отступов, радиусы и префиксы. Исходный яркий синий #1b73f8 сохранён для бренда; для белого мелкого текста кнопок выбран #1463db. Это предложение нового пакета, а не утверждённый корпоративный брендбук. Зелёный, красный и янтарный сохранены только для смысловых состояний.

Никакие реальные сотрудники, события, БД, конфигурации серверов и секреты в пакет не включены. Отдельного chart engine, серверной валидации, авторизации и производственной логики здесь нет.
