# Исходные Excel начального набора

Здесь находятся шесть побайтовых копий книг, использованных в `winter.json`.
Имена файлов состоят из SHA-256; исходные имена и пути сохранены в
`manifest.json` и в БД. При скачивании через LIMS файл получает исходное
имя книги. Содержимое оригиналов в `Пена/pena/` не изменялось.

Книги входят в Docker-образ вместе с приложением. Для скачивания нужны
вход в LIMS и активный профиль; доступны роли автора и читателя.
Путь из БД не используется для произвольного чтения файлов: разрешены
только пары исходного пути и SHA-256 из реестра. Перед выдачей копии
проверяется её контрольная сумма.

Проверка полного комплекта из папки `LIMS`:

```bash
python3 scripts/check_initial_sources.py
```

Та же проверка выполняется при сборке Docker-образа. Отсутствующая книга,
несовпадение реестра с `winter.json` или неверный SHA-256 прерывают сборку.
