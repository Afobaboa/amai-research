# Пилот LIMS для зимней пены

Отдельная рабочая папка для документации и реализации облачного пилота LIMS с ИИ-агентом. Материалы версионируются в самостоятельном Git-репозитории этой папки.

- [Согласованная архитектура](architecture.md) — функциональный объём, стек, доступ, развёртывание и перенос зимней пены. Зафиксирована 01.11.2026.
- [Утверждённая модель данных пилота](data-model-proposal.md) — версия 1.0, утверждена пользователем 01.11.2026. Ядро: рецептуры, карточки испытаний, условия, результаты, наблюдения, записанная обработка и первичные источники. Исследовательские задачи, операции изготовления, фактические навески и физические объекты отложены.
- [Таблицы, связи и примеры заполнения](data-model-walkthrough.md) — назначение каждого поля, ER-диаграммы, 316.8/316.26 и конфликтующие STP 40; [DDL ядра](examples/relational/schema.sql) содержит 20 таблиц, 110 полей и 40 FK. [Будущее расширение](examples/relational/optional-process-extension.sql) отделено и к пилоту не применяется. Генерация INSERT/JSON/таблиц из первичных Excel: `Пена/.venv/bin/python LIMS/scripts/build_relational_example.py`. Рабочая БД не изменялась.
- [Свидетельства из Excel](analysis/excel-source-evidence.json) и [скрипт независимого чтения XLSX](scripts/inspect_excel_sources.py) — реестр книг/листов и адресные примеры. Запуск из корня рабочей папки: `Пена/.venv/bin/python LIMS/scripts/inspect_excel_sources.py`. Parquet не используется как источник истины.

На этом этапе утверждены архитектура и сокращённая модель, подготовлены воспроизводимые примеры из Excel. Приложение, рабочие миграции, агент, импорт и развёртывание ещё не реализованы.

Предыдущие исследования и демонстрации находятся в [experiment-tracking/](../experiment-tracking/README.md), исходные материалы по пене — в [Пена/](../Пена/README.md).
